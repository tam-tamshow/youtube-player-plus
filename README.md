# YouTube Player Plus

YouTubeの動画プレーヤーに、追加の再生操作を表示するChrome拡張です。

MVPでは、動画の中央付近に次のボタンを追加します。

- 10秒巻き戻し
- 10秒早送り

## Chromeへの読み込み方

1. Chromeで `chrome://extensions/` を開く
2. 右上の「デベロッパー モード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」を選ぶ
4. このリポジトリのルートディレクトリを選ぶ
5. YouTubeの動画再生ページを開く（すでに開いている場合は再読み込みする）

## 動作確認

```sh
npm run check
```

外部パッケージのインストールは不要です。Node.jsの構文チェックと、時間移動ロジックのテストを実行します。

## 拡張方針

- `src/core.js`: 既定設定、操作ボタン定義、時間移動ロジック
- `src/content-script.js`: YouTubeプレーヤーへのボタン設置と操作イベント
- `src/content.css`: プレーヤー上の見た目と配置

秒数は `DEFAULT_SETTINGS.seekSeconds` に集約しています。将来、設定画面を追加する際は保存済み設定でこの値を上書きし、操作ボタンを増やす際は操作定義と対応する処理を追加する想定です。
